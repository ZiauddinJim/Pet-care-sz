# Pet Care

## Purpose
Pet Care in Winter helps pet owners keep their furry friends safe, warm, and healthy during the cold season.  
From grooming and nutrition tips to protection against harsh weather, it provides easy guides and trusted advice to ensure pets stay happy and comfortable all winter long.

---

## Live URL
[View Project](https://pet-care-sz.pages.dev/)

---

## Key Features
- Single Page Application (SPA) using React Router  
- User authentication (Email/Password) and Google Sign in with Firebase  
- Protected and public routes for secure navigation  
- Context API for global authentication and state management  
- Responsive design built with Tailwind CSS  
- Conditional rendering based on user status  
- Persistent login state using Firebase Auth  
- SweetAlert2 and Toast notifications for alerts and messages  
- Clean folder structure and reusable React components  
- Animations and transitions using AOS, Animate.css, and React Spring  
- Interactive UI with DaisyUI, React icon and Lucide React icons
